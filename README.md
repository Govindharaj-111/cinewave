# 🎬 Movie Ticket Booking Management Application

## 📌 Project Overview

The Movie Ticket Booking Management Application is a Pega Platform based application designed to simplify and manage the complete movie ticket booking process.

The application helps customers request movie tickets, check show availability, calculate booking costs, confirm bookings, and manage booking information efficiently.

## 🎯 Project Objectives

- Allow customers to submit movie ticket booking requests.
- Check movie show and seat availability.
- Calculate the total booking cost.
- Confirm booking requests.
- Maintain movie and show information.
- Review and track booking details.
- Provide a smooth workflow from booking request to confirmation.

## 🛠️ Technology Used

- Pega Platform
- Pega App Studio / Infinity
- Pega Blueprint
- GitHub
- Case Management
- Data Objects
- Workflow Automation

## 🔄 Main Workflow

1. Submit Movie Ticket Request
2. Check Show Availability
3. Calculate Booking Cost
4. Confirm Booking Request
5. Maintain Movie and Show Data
6. Review Booking Details
7. Process Ticket Booking
